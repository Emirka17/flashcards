# Flashcards Web Application

## Описание проекта
Full-stack веб-приложение для изучения иностранных слов. Проект реализует механику создания карточек (flashcards) с возможностью категоризации по тегам и режимом самопроверки. 

Приложение построено на базе микросервисной архитектуры с полным разделением клиентской и серверной частей.

## Архитектура и стек технологий
Проект состоит из трех изолированных компонентов:

1. **Frontend (User Interface):** 
   - Написан на **Python** с использованием фреймворка **Streamlit**.
   - Отвечает исключительно за отображение данных и взаимодействие с пользователем.
   - Взаимодействует с сервером через HTTP/REST запросы (библиотека `requests`).

2. **Backend (REST API):**
   - Написан на **Go (Golang)** с использованием стандартной библиотеки `net/http` и драйвера `lib/pq`.
   - Обрабатывает бизнес-логику, маршрутизацию и формирует JSON-ответы.
   - Работает независимо от клиента, что позволяет в будущем подключить мобильное приложение (iOS/Android) к этому же API.

3. **Database:**
   - **PostgreSQL** (облачное хранилище Neon).
   - Нормализованная реляционная структура (отдельные таблицы для слов, уникальных тегов и таблицы связей "много-ко-многим").

4. **Инфраструктура и Деплой:**
   - **Docker & Docker Compose:** полная контейнеризация для локальной разработки.
   - **Back4App (CaaS):** хостинг Go-контейнера.
   - **Streamlit Community Cloud:** хостинг фронтенд-приложения.

## Основной функционал
- Добавление новых слов с переводом, примером использования и тегами (категориями).
- Просмотр словаря с фильтрацией по конкретным тегам.
- Режим "Тренировка": пошаговый опрос с проверкой перевода на основе выбранной категории (включая режим тестирования по всем словам).
- Изолированное хранение данных в облачной СУБД.

## Локальный запуск (Docker)
Для запуска проекта локально требуется установленный Docker.

1. Клонируйте репозиторий:
   git clone https://github.com/ВАШ_ЛОГИН/flashcards.git
   cd flashcards

2. Создайте файл конфигурации окружения:
   - Переименуйте `.env.example` в `.env` (или создайте новый файл `.env`).
   - Добавьте в него строку подключения к PostgreSQL:
     DATABASE_URL=postgres://user:password@host/database_name?sslmode=require

3. Запустите контейнеры:
   docker-compose up --build
